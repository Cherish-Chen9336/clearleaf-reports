# Clearleaf site reports

Clearleaf is an ad blocker for Chrome, based on
[uBlock Origin Lite](https://github.com/uBlockOrigin/uBOL-home) (GPL-3.0).

This repository collects reports about websites that don't work well with
Clearleaf: ads that get through, or a site that breaks when blocking is on.

To report a site, open the Clearleaf popup on that site, choose
**Site looks broken?**, then **Send a report**. The report form opens here,
filled in for you. A GitHub account is needed.

What a report shares: the address of the page you choose, the kind of
problem, and Clearleaf's settings (filter lists and blocking level). Nothing
is sent until you submit the form on GitHub.
